## 📌 Proje Özeti

Geleneksel web sitelerinde yer alan tekil WhatsApp butonları müşteriyi çoğu zaman genel bir sohbet penceresine yönlendirirken; **Acente WhatsApp Köprü Oluşturucu**, ziyaretçiyi doğrudan ihtiyacı olan departmana (Fiyat Teklifi, Hasar Destek, Poliçe Sorgulama veya Ofis Konumu) ulaştıran akıllı bir mikro arayüz üreticisidir.

Acentelerin herhangi bir kodlama veya veritabanı bilgisine ihtiyaç duymadan, saniyeler içinde kendi özelleştirilmiş WhatsApp menülerini tasarlayıp tek bir HTML kod bloğu olarak web sitelerine (WordPress, Wix, Özel Yazılım vb.) entegre etmelerini sağlar.

---

## ✨ Öne Çıkan Özellikler

* 🎯 **Dinamik Buton & Departman Yönetimi:** İhtiyaca göre sınırsız sayıda hizmet butonu ekleme, çıkarma ve metin özelleştirme.
* 🗺️ **Akıllı Adres & Konum Dönüştürücü:** Girilen ofis adresini otomatik olarak tek tıkla açılan Google Haritalar yönlendirmesine çevirme.
* 💬 **Önceden Tanımlı Mesaj Şablonları:** Müşterinin tek tıkla acenteye hazır teklif veya hasar sorgu metniyle ulaşması.
* 📱 **Gerçek Zamanlı Cihaz Simülatörü:** Yapılan tüm başlık, numara ve buton değişikliklerini yandaki telefon ekranında anında canlı test etme imkânı.
* ⚡ **Evrensel & Hafif Entegrasyon:** Web sitesinin açılış hızını etkilemeyen, sıfır harici kütüphane bağımlılığına sahip saf HTML/CSS/JS kod çıktısı.

---

## 🛠️ Teknoloji Yığını

* **Arayüz / Tasarım:** Semantic HTML5, Tailwind CSS (Slate / Light Clean Design System)
* **İkonografi:** Lucide Icons CDN
* **Çekirdek Motor:** Vanilla ES6+ JavaScript (Sıfır framework bağımlılığı)
* **Dağıtım / CI-CD:** Vercel Edge Network
