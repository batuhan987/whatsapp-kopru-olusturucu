# 🚀 Acente WhatsApp Köprü Oluşturucu (Pro)

Web siteniz için saniyeler içinde profesyonel bir **WhatsApp Destek Paneli** oluşturun! Bu araç, özellikle acentelerin ve küçük işletmelerin müşterileriyle hızlı iletişim kurması, teklif alması ve konum paylaşması için geliştirilmiştir. 💼✨

---

## ✨ Özellikler

* **Dinamik Buton Yönetimi:** İstediğiniz kadar buton ekleyin veya çıkarın. ➕➖
* **Akıllı Adres Dönüştürücü:** Sadece adresinizi yazın, sistem onu otomatik olarak Google Haritalar linkine çevirsin! 📍🗺️
* **Özel Mesaj Şablonları:** Her departman için (Teklif, Hasar, Bilgi) farklı karşılama mesajları belirleyin. 💬
* **Anlık Önizleme:** Yaptığınız değişiklikleri sağdaki simülasyonda anında görün. 📱
* **Kolay Entegrasyon:** Tek bir HTML kodu ile tüm web sitelerine (WordPress, Wix, Özel Yazılım) uyumlu. 🔌

---

## 🚀 Nasıl Kullanılır?

1.  [**Buraya Tıklayarak Araca Gidin**](https://batuhan987.github.io/whatsapp-kopru-olusturucu/) 
2.  Acente adınızı ve WhatsApp numaranızı girin.
3.  İhtiyacınıza göre butonları ve mesajları özelleştirin.
4.  **"Kodu Kopyala"** butonuna basın.
5.  Kopyaladığınız kodu web sitenizin `</body>` etiketinden hemen önce yapıştırın. 🎉
